# 동래아 공동육아 🐍

동래래미안아이파크 엄마 아빠들의 공동육아 모임 홈페이지와 자료예요.

- 홈페이지: https://kimddubuck.github.io/coparenting/
  - 홈: 모임 소개, 우리 약속, 다가오는 일정
  - 일정·공지: 모임 날짜와 공지 이미지, ⚡ 번개, 지난 모임
  - 놀이 고르기: ① 혼자서도 할 수 있어요(몇 주 반복) + ② 새로운 경험(자주 새로)
  - 익명게시판: 배웠으면 하는 행동, 해 봤으면 하는 경험, ⚡ 번개 요청, 자유
- 고칠 곳: 놀이 `plays.js`, 일정 `schedule.js`
- 작업 규칙: `CLAUDE.md`, 게시판 설정: `의견게시판_설정.md`
